## 3. Revision Guidelines

- **Deep revision:** Re-solve representative problems independently, revisit core patterns, and practise explaining the approach and complexity.
- **Revise thoroughly:** Re-solve a broad selection of previously completed problems and add new problems where pattern recognition is weak.
- **Revise:** Revisit representative problems and make sure you can implement the common patterns without looking at solutions.
- **Selective revision:** Focus on common interview patterns and problems where you previously needed hints.
- **Quick revision:** Review the key techniques and solve a small set of representative problems.

Prioritize independent problem-solving, clean Java implementation, complexity analysis, and explaining trade-offs over increasing the total number of solved problems.
